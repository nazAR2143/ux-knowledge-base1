## [1.0.0] — 2026-11-09

### 🎉 Initial Release

#### Added
- **01 — UX Foundations:** Nielsen's 10 Heuristics, Cognitive Load Theory, Gestalt Principles, Mental Models, Laws of UX (10 laws with application), Hick's Law
- **02 — Visual Design:** Typography (modular scale, body text rules), Color Theory (WCAG contrast, design tokens), Spacing (8-point grid), Visual Hierarchy (F-pattern/Z-pattern), Grid Systems (12-column + container queries), Icons & Imagery, Motion & Animation (prefers-reduced-motion), Design Tokens
- **03 — Accessibility (a11y):** WCAG 2.2 full criteria review, Semantic HTML, ARIA rules & patterns, Keyboard Navigation (skip links, tab order), Focus Management (focus trap pattern), Screen Reader support (NVDA, VoiceOver shortcuts), Images & Media (alt text decision tree), Forms Accessibility, Cognitive Accessibility, Testing Tools matrix
- **04 — Navigation & IA:** IA Principles, Card Sorting guide, Navigation patterns comparison, Mega Menus, Breadcrumbs (accessible + Schema.org), Search UX (accessible autocomplete, no-results page), Pagination patterns, Wayfinding
- **05 — Mobile & Responsive:** Mobile-first philosophy, Responsive breakpoints, Touch target guidelines (WCAG 2.5.8, Apple HIG, Material), Touch gestures, Mobile typography, Bottom tab bar pattern, Hamburger menu, Responsive images, PWA basics
- **06 — Performance UX:** Core Web Vitals (LCP, INP, CLS) with targets, Optimization strategies, Perceived performance, Loading states & skeleton screens, Image optimization pipeline, JavaScript performance (scheduler.yield, layout thrashing), CSS performance, Real User Monitoring
- **07 — Forms & Inputs:** Form layout principles (single-column research), Labels & placeholders, Input types & inputmode, Validation & error handling, Error summary, Multi-step forms, Password fields with show/hide, Autocomplete/autofill (WCAG 1.3.5), File uploads
- **08 — Content & UX Writing:** UX Writing principles, Plain language (word choice guide), Microcopy patterns, Error message formula, Empty states, Onboarding copy, Button/CTA labels, Tone & voice, Inclusive language guide, i18n basics (Intl API)
- **09 — Testing & Research:** Research methods landscape, Usability testing (task writing, session script, severity scale), Moderated vs. unmoderated testing, User interviews (question framework, anti-patterns), Surveys (NPS, SUS, CSAT), Analytics & session recordings, A/B testing (statistical significance), Card sorting & tree testing, Heuristic evaluation, Research reporting template
- **10 — Checklists:** Pre-launch UX checklist, WCAG 2.2 AA audit template (all 50 criteria), Performance audit template, Mobile UX audit, Forms audit, Content audit, Heuristic evaluation template, Design handoff checklist
- **README:** Knowledge map, section index with difficulty ratings, quick-start guides by role (Developer, Designer, Full-Stack, QA)
- **CONTRIBUTING.md:** Style guide, commit format, source quality standards
- **LICENSE:** MIT
