## 🚀 Quick Start by Role

### 👨‍💻 Frontend Developer
1. Start with [Performance UX](docs/06-performance-ux/README.md) → Core Web Vitals
2. Study [Accessibility](docs/03-accessibility/README.md) → ARIA & semantic HTML
3. Reference [Forms & Inputs](docs/07-forms-inputs/README.md) → validation patterns

### 🎨 UI/UX Designer
1. Begin with [UX Foundations](docs/01-foundations/README.md) → Heuristics
2. Deep dive into [Visual Design](docs/02-visual-design/README.md) → Typography & Color
3. Learn [Navigation & IA](docs/04-navigation-ia/README.md)

### 📱 Full-Stack Developer
1. Review [Mobile & Responsive](docs/05-mobile-responsive/README.md)
2. Study [Accessibility](docs/03-accessibility/README.md) compliance
3. Use [Checklists](docs/10-checklists/README.md) before every release

### 🧪 QA / Researcher
1. Focus on [Testing & Research](docs/09-testing-research/README.md)
2. Use [Checklists & Audits](docs/10-checklists/README.md)
